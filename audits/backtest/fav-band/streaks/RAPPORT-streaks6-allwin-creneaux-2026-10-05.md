## 4. Synthèse concrète

### Streaks =6 / ≥6
- 6 streaks **exactement 6** ; 21 streaks **≥ 6** (table §1).

- Récurrence **≥6** même heure de début : 06h ×3j, 09h ×2j, 14h ×2j, 19h ×2j, 22h ×3j.

### Slots / jours all-win
- **Aucun jour calendaire 100%.**

## 5. Caveats (petits n)

- **n par heure agrégée ≈ 17–26**, 5–8 jours distincts : un WR 100% ou 95% sur un bin 1h reste **fragile** (IC larges ; voir rapport parent, 23h = 20/21).
- Un créneau **jour × heure** à 100% avec n = 2–4 est attendu sous WR baseline 70% (P(4 wins) ≈ 24%) — **ne pas traiter comme un filtre**.
- Seulement **~10 jours** de sim ; couverture horaire inégale (trous >2 h) ; sizing changé le 01/10.
- Les streaks traversent les trous de sim ; définir autrement raccourcirait certains runs.
- Aucun de ces créneaux 100% n'est un filtre validé ; pas de test de réplication hors période dans ce follow-up (le parent montrait que 23h ne se répliquait pas sur le backtest).
- Métriques uniquement descriptives ici : pas de p-values nouvelles inventées.
