# Dip-guard — rapport de backtest (2026-09-16)

> **Statut : NEGATIF — non recommandé en l'état.** Le signal d'entrée brut a une
> espérance négative sur l'univers complet ; aucune combinaison stop/trailing
> testée ne le retourne en positif. Les exits testés réduisent les dégâts
> (+$207 vs hold pur, DD −32 %) mais ne créent pas d'edge.

## 1. Spécification (demande utilisateur, formalisée)

| Règle | Formalisation sim | Valeurs |
|---|---|---|
| **Entrée** | elapsed ≤ 300 s après windowStart ; un token (Up ou Down) cote **ask ∈ [0.30, 0.40]** → achat FOK. Si les deux tokens sont dans la bande → le moins cher. Spread ask−bid ≤ 0.05 ; profondeur ask ≥ taille (FOK one-shot) ; taille = min($15/ask, 30 sh) ≥ 5 sh. | bande 0.30–0.40, fenêtre [0, 300]s |
| **Stop-loss** | bid du token **détenu** ≤ **0.20** → sell marketable (walk 3 niveaux de bids, worst-price = trigger − 2 ticks, kill → retry tick suivant). Inactif si trailing armé. Variante littérale testée : actif seulement 120 s après l'entrée. | 0.20 (alt 0.15) |
| **Trailing stop** | bid ≥ **0.50** arme le trailing ; stop = **pic de bid − 0.20** ; déclenché quand bid ≤ stop (même mécanique de sell). | arm 0.50, dist 0.20 |
| **Sinon** | hold-to-resolution (payout 1/0). | — |
| **Limites** | 1 entrée par fenêtre, pas de ré-entrée après sortie. | — |

```
elapsed  0s        300s                    900s
         |--- FENETRE ENTREE ---|
         |  ask 0.30-0.40 -> BUY |
         |                       |  bid<=0.20 -> SELL (stop)
         |                       |  bid>=0.50 -> arme trail (pic-0.20)
         |                       |  bid<=pic-0.20 -> SELL (trail)
         |                       |  sinon -> hold -> resolution (payout 1/0)
```

Exécution fidèle : sorties pricées sur le carnet du token **détenu**
(leçon dip-revert), walk FOK worst-price avec slippage cap 2 ticks
(leçon clob-market-orders : un stop au prix exact du trigger ne remplit
que le niveau 1 et se fait tuer en crash), kill → retry tant que la
condition tient.

## 4. Diagnostic

1. **Le problème est l'entrée, pas les exits.** Hold-to-resolution pur :
   WR 34 % pour un prix moyen 0.388 — le marché cote ce token à sa
   probabilité réelle (breakeven implicite 38.8 %), sans biais de
   retournement. Acheter l'underdog 0.30–0.40 en début de fenêtre = payer
   le juste prix d'un événement coin-flip biaisé contre soi.
2. **Les exits aident mais ne suffisent pas.** Base vs HOLD-ref :
   **+$207** de PnL et DD **832 → 563 (−32 %)**. Le trailing est
   systématiquement meilleur que le stop sec (trail-only −451 vs
   stop-only −528) : les sorties capturent des rebonds que le hold
   rend à la résolution. Le stop littéral « 2 min » est pire que le stop
   permanent (−578 vs −457) : il coupe la protection exactement quand le
   token continue de s'effondrer.
3. **Tighten la bande ne sauve pas.** band 0.30–0.35 = moins de pertes
   (−298) mais toujours négatif, et le stop y déclenche plus souvent
   (233 stops sur 439) — whipsaw structurel du sous-jacent.
4. **Par jour** : 6 j rouges / 9, aucun jour ne dépasse +$59 (base). Le
   signal n'a pas de régime porteur dans l'échantillon.
5. **Tie-break mécanique** : quand les DEUX tokens sont 0.30–0.40 (somme
   ≤ 0.80, rare), on achète le moins cher — ces trades sont marginaux.

## 5. Verdict

- **Ne pas implémenter en moteur live en l'état** : espérance négative
  confirmée sur 487 trades / 494 fenêtres, aucun variant positif sur
  16 configs, t-stat négatif trivial (EV/share constamment < 0).
- La structure d'exit (trailing 0.20 armé à 0.50) est la seule partie du
  design qui apporte de la valeur (+$207 vs hold, DD −32 %) — réutilisable
  comme module sur un **autre signal d'entrée à espérance positive**.
- Réserves honnêtes : sim tick-lecture (pas de latence FOK réelle), un
  seul régime de marché (9 jours), univers btc-15m uniquement.

## 6. Si l'on veut continuer l'axe

Axes non testés ici (à valider avant tout code) : bande décalée côté
favori (0.55–0.65 = territory dip-revert/flip-confirm déjà validés),
direction inversée (acheter le favori quand l'underdog est 0.30–0.40 —
c'est proche de dip-revert), ou stop asymétrique (0.15 seulement, arm 0.45).
Le stop « 2 minutes » de la spec initiale est **mesuré mort** : à ne pas
réintroduire.
