## Caveats

- « Consécutif » = positions consécutives **du jour** (tri fenêtre marché asc). Les fenêtres sans trade fav-band entre deux wins n'interrompent pas le run ; seule une `lost` le casse (et les 2 `sold` du 10-01 ont été exclues sans casser).
- Le "span" d'une bande = [début du 1er run, fin du dernier run] ; le WR "bande" compte **toutes** les positions de la fenêtre horaire (y compris les jours sans streak) — pour savoir si le créneau est intrinsèquement bon.
- Les heures de tranche = heure de début de fenêtre marché ; l'entrée fav-band a lieu après `favBandMinElapsedSec` dans la fenêtre (décalage de quelques minutes).
- 1 fenêtre(s) marché contient 2 positions fav-band : `btc-updown-15m-1790402400` (26/09 02:00 ET) — buy Down fill 0.68 (won +1.6) puis buy Up fill 0.10 (lost −0.5), ordonnées Down→Up dans la séquence.
- Slug non parseable : 0 position(s) ignorée(s).
